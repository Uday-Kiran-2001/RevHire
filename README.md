RevHire – Console Job Portal Application

RevHire is a Java-based console application that connects Job Seekers and Employers on a single platform. Job seekers can build profiles, manage resumes, search and apply for jobs, while employers can post jobs and manage candidates. The system is designed with a modular architecture and can be extended into a web/microservices application in future.

🔹 Key Features
Job Seeker

Register & Login

Create and manage resume (education, skills, experience, projects)

Search jobs using filters (role, location, experience, salary, company, job type)

One-click job application

View application status (Applied / Shortlisted / Rejected / Withdrawn)

Withdraw applications

In-app notifications

Employer

Company registration & login

Create and manage job postings

View applicants with resume details

Shortlist / Reject candidates (bulk supported)

Filter applicants by skills, experience, education

Manage company profile

🔐 Authentication

Separate flows for Job Seekers and Employers

Login with email/password

Change password

Forgot password via security questions
